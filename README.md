# classRoom

Ein Werkzeugkasten für Lehrerinnen und Lehrer: verschiedene kleine Tools, die sich direkt während des Unterrichts nutzen lassen – schnell erreichbar, ohne Einarbeitung und gut lesbar am Beamer oder Smartboard.

## Geplante Funktionen

- **Timer & Stoppuhr** – Countdown für Arbeitsphasen, Tests oder Pausen
- **Zufallsauswahl** – Schülerin oder Schüler zufällig aufrufen
- **Gruppen bilden** – Klasse automatisch in Gruppen aufteilen
- **Lautstärke-Ampel** – zeigt über das Mikrofon an, wie laut es in der Klasse ist
- **Klassenlisten** – Klassen anlegen und für die anderen Tools wiederverwenden

Die Liste wird mit dem Projekt wachsen.

## Ziele

- Funktioniert im Browser, ohne Installation
- Große, gut sichtbare Darstellung für die Projektion
- Bedienung mit wenigen Klicks während des Unterrichts
- Schülerdaten bleiben lokal auf dem Gerät
